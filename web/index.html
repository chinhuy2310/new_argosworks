🎫 Atlassian Jira 외부 연동 (선택 사항)

비활성화

Atlassian Jira를 연동할 기업만 활성화하십시오. 비활성화 시 사내 업무 관리 기능이 100% 로컬 독립 모드로 동작합니다.

Jira 자동 동기화 활성화 (선택 사항)

※ 부서별 매핑에 등록되지 않은 부서나 미지정 사용자가 티켓을 등록할 때 자동 지정되는 대체 프로젝트 키입니다.

※ ARGOS 이름 → Jira 이름/username/email 매핑(JSON). 같은 매핑을 양방향으로 사용합니다: 로컬 카드를 Jira로 올릴 때 담당자/보고자 지정, 그리고 Jira에서 동기화된 카드를 로컬 사용자로 인식 (“내 업무”/개인 캘린더/권한 판정)할 때 모두 적용됩니다.

🔔 실시간 알림 웹훅 연동 (Outgoing Webhooks)

대기

표준 JSON POST 페이로드 ({event, title, content, sender, link_id, tag})를 전송합니다.
